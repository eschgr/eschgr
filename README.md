### What I'm into
What I really want to do is build worlds—rich, explorable, alive. So I'm learning how to use the tools that can get me there: procedural generation to grow worlds from rules rather than hand-crafting every inch, and AI to do the work of many hands. It's experimentation, plain and simple—seeing how far these capabilities go, and how much one person can build with them.
